Book Appointment

Request Body schema: application/json
required

required
string (Call Id)

The callSid of the start message that opened the call. Never minted by the team.

patient_id
required
string (Patient Id)

The patient's id from the directory lookup -- never from what the caller said.

provider_id
required
string (Provider Id)

The provider who will see the patient, from the directory.

location_id
required
string (Location Id)

The site the appointment is at, from availability.

appointment_type_id
required
string (Appointment Type Id)

The kind of visit, from availability.

slot
required
string <date-time> (Slot)

The appointment's start, with an explicit timezone offset. Compared in Europe/Madrid to the exact minute.

required
string (Insurer)

Which of the patient's plans the appointment is billed against. A patient may hold two, and only one may cover what they asked for.

Last day of the window, inclusive.

Examples: provider_id=PR05

Specialty Id (string) or Specialty Id (null) (Specialty Id)
Examples: specialty_id=dermatology

Patient Id (string) or Patient Id (null) (Patient Id)
